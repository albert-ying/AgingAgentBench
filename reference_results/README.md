# Reference predictions

Each prediction CSV uses `record_id`, `call`, `direction`, `p_value`, `effect`,
`effect_unit`, `paper_id`, and optional source metadata. A call is `higher`, `lower`, or
`not significant`. A blank call with `status=direction_only` preserves an
available direction when the source has no inferential result. Missing rows
are unavailable predictions or abstentions.

`clockbase_paper_groups.csv` uses the paper's groups and the released tests.
The `_welch` variant uses a Welch test and the paper's measure. The
`_individual_readers` variant adds individuals identified by two readers.
The `_guarded` variant preserves the Welch calculations after the source
analysis dropped clock outputs above 1,000 years in four results. Two of
these rows enter the 30-record year-effect set. The guarded variant marks
age and age-acceleration effects with `effect_unit=years`.

`clockbase_agent_stored.csv` holds the stored agent results.
`clockbase_atlas_welch.csv` holds the earlier Welch-only atlas results, and
`clockbase_atlas_verified.csv` holds the final verified atlas results.
`language_model_*.csv` contains predictions without data.
`constant_higher.csv` calls every result higher and significant.

`agent_*_raw.csv` holds the six reruns' reported predictions.
`agent_*_recomputed.csv` holds the released tests on their selected samples.
Their directions are oriented to the published groups.

`cohorts.json` lists the fixed comparison sets. The framework intersections
contain 68, 82, and 70 records, of which 59, 69, and 60 have classifiable
published calls. `paper_groups_welch113` restricts the Welch analysis to the
113 DNA methylation records used for the paper's reported findings.

`effect_pairs_years.csv` holds the 30 eligible effect pairs from seven papers.
The released-test source CSV has no effect estimates, so their columns are
empty in `clockbase_paper_groups.csv` and
`clockbase_paper_groups_individual_readers.csv`.

`expert_truth.csv` holds calls for the complete expert-defined groups.
The `expert_agent`, `expert_released`, and `expert_candidate` files hold the
corresponding predictions. The candidate variant gives the manuscript's final
expert agreement counts. Rows with `label_unconfirmed=False` have
confirmed arm orientation. These files contain results without the mouse
annotation's group definitions or sample labels.

`paper_metrics.json` contains selected archived metric blocks for regression
tests. `export_notes.json` records input checksums, modification timestamps,
row counts, and bootstrap settings. Both are independent of test outputs.

`supplementary_table_s18.csv` exports the values of the published S18
worksheet. Expert results in that table include rows with unconfirmed arm
orientation unless their note says `labels confirmed`. Its companion JSON
records the workbook checksum and caption.
`source_definitions.json` records hashes of the original scorer, prompt code,
and test definitions. `reproduced_metrics.json` is generated by the standalone
scorer and is kept separately from the archived test expectations.

The expert truth columns `test` and `method` identify the reference test for
each result. See the [test selection rules](../data/expert/README.md#test-selection).
Confirmed arm orientation gives 86/87 mouse and 121/123 human DNA methylation
agreement for the final candidate; including unconfirmed orientation gives
88/89 mouse and 157/163 human agreement.

The source run is `final-2026-11-13`. `atlas_shared92` contains
the classifiable shared atlas calls. `atlas_shared_covered` retains the full
shared sampling universe for source bootstrap comparisons. `atlas_agent_shared`
and `paper_models_shared` reproduce the corresponding summary-table cohorts.
`same_sample_calls.csv` contains only published and stage calls for matched
contrasts. `paper_table.md` preserves the paper's source table.

The `agent_*_atlas_frozen.csv` files preserve each rerun's recorded atlas
baseline. Those comparisons use their original source predictions;
`clockbase_atlas_verified.csv` uses the current verifier run.
